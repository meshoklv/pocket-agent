# Pocket Agent

[English](README.md)

![Pocket Agent](docs/cover.png)

**Кодинг-агент, который целиком живёт на iPhone: локальная модель Gemma читает файлы проекта и предлагает правки — но ничего не пишет, пока вы не нажмёте «Применить».**

## Почему это круто

- **Оффлайн в кармане.** Модель работает на телефоне. После разовой загрузки модели сеть не нужна; файлы, задачи и переписка никуда не уходят.
- **Безопасно по построению.** Агент умеет ровно четыре действия: список файлов, чтение, запись, завершение. **Любая запись — только после вашего подтверждения**, с разницей «было/стало». Отказ возвращается модели, и она предлагает другое.
- **Только своя папка.** Агент трогает лишь ту папку, которую вы ему показали.
- **Честно про малую модель.** Модель на ~2 млрд параметров не тянет длинные цепочки действий, поэтому агент работает короткими шагами с человеком в петле.

## Возможности

- Чат, выбор папки проекта, карточка подтверждения с diff
- Менеджер моделей: загрузка, импорт из «Файлов», проверка SHA-256, проверка памяти
- В коде есть несколько движков (LiteRT-LM по умолчанию, MLX, llama.cpp), удалённые провайдеры, экспериментальные генерация картинок и веб-площадка

## Требования

- iPhone, iOS 17+; для модели по умолчанию в каталоге приложения указан класс **8 ГБ ОЗУ** (iPhone 15 Pro и новее). *Из каталога, автором релиза не проверялось.*
- ~2 ГБ под модель
- Для сборки: Mac, Xcode 26.2, XcodeGen, аккаунт разработчика Apple
